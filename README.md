### Hi, I'm João 👋

**Senior Software Engineer — I build correctness-critical fintech systems and the data platforms
behind them, and I'm going deep into applied AI.**

A decade in software, the last four building the accounting platform that closes companies' books
at [Blue Onion](https://www.blueonionlabs.com/). I work full-stack but go deepest where it's
hardest to get right — **PostgreSQL at scale** and **double-entry accounting correctness**, where a
wrong sign is a misstated ledger, not a cosmetic bug. I write the design doc before the code, and I
care more about the problem than any single solution.

#### 🎯 Now

- **Accounting & general ledger** software (NetSuite / QuickBooks) over **millions of orders,
  payments, and ledger entries** — a Rails + React app backed by a dbt / Airflow / BigQuery pipeline.
- A **postgraduate in Applied AI Engineering** — RAG, autonomous agents via the **Model Context
  Protocol (MCP)**, prompt engineering, and MLOps.
- **Goal:** bring AI-first architecture into production *without* losing the reliability discipline
